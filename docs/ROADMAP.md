## 🎯 التركيز الاستراتيجي (قرار 2026-09-22)

ركيزتان أساسيتان للميزة التنافسية — كل فكرة جديدة تُقاس عليها:

1. **أين أشيائي؟** — ذاكرة الأماكن والأغراض: تسجيل موثوق، استرجاع دقيق، إجابة بمصدر.
2. **العائلة** — كل ما يخص تنسيق البيت: مهام مشتركة، تسوق، مواعيد، لحظي وتشاركي.

## 🔭 الرؤية طويلة المدى (2026-09-22)

**مقولة المنتج (2026-09-22):** التطبيق **يستقبل الأحداث** من الناس **ويجاوب على أسئلتهم** — ومع الأيام يتكوّن عندهم أرشيف لأشيائهم ومصاريفهم وتفاعلهم العائلي، داخل فكرة التطبيق نفسه (وليس كخدمة تخزين).
- نحن شركة **ذاكرة**، مش شركة تخزين. كل قرار منتج يُقاس بـ"هل يجعل التطبيق يجاوب أحسن؟" لا "هل يخزّن أكثر؟"
- **قرار معلق:** سياسة الاحتفاظ بالصوت — الخيارات: (أ) احتفاظ كامل للكل، (ب) الصوت ميزة مدفوعة (المقترح)، (ج) نص فقط بدون صوت. يُحسم قبل M4.

**أرشيف حياة الشخص والعائلة اليومية.**
- كل تسجيل = لحظة موثقة: الصوت الأصلي + النص + التاريخ + المتحدث + المساحة.
- مع الوقت: أرشيف يومي **قابل للسؤال** ("شو كنا نحكي قبل سنة؟") — منظّم (مهام/مواعيد/أماكن/مشتريات/وعود) وليس أرشيف نصوص خام.
- الميزة الدفاعية: قيمة الأرشيف **تتراكم** مع الاستخدام — بعد سنة مستحيل المستخدم يترك تطبيق فيه ذاكرة عيلته وصوت أحبته.
- الأرشيف هو **الرؤية**؛ الاستخدام اليومي ("وين أغراضي؟ شو مهامي؟") هو **المدخل** — الناس تشترك للمشكلة اليومية، والأرشيف يجعلها لا تغادر أبداً.
- ملامح مستقبلية: "بهذا اليوم قبل سنة/سنتين"، حفظ أصوات الأحبة، تاريخ العائلة عبر الأجيال.
- ملاحظة تقنية: الاحتفاظ بالصوت الأصلي ضروري للتوثيق ("إجابة بمصدر") — مع سياسة ضغط/أرشفة للملفات القديمة لضبط تكلفة التخزين.

## ✅ متفق عليها (جاهزة للتنفيذ)

### 1. زر تبديل بين إدخال صوتي ونصي
- عند إضافة ملاحظة: toggle بين 🎙️ مايك و ⌨️ نص.
- نفس الفكرة لميزة السؤال والجواب: سؤال صوتي أو كتابي.
- الهدف: الناس اللي بتحب تكتب والناس اللي بتحب تسجّل — الطريقتين مدعومتين.
- ملاحظة تقنية: النص المكتوب بيتخطى التفريغ الصوتي وبيروح مباشرة للاستخراج (extract).

### 2. السؤال والجواب (Q&A) — "وين المفك؟"
- المستخدم بيسأل صوتياً أو كتابةً، والتطبيق بيجاوب من الملاحظات المحفوظة.
- مثال: "وين حطيت المفك؟" ← "بالدرج الثاني بالمطبخ، سجّلتها يوم الثلاثاء."
- بيدعم الإدخال الصوتي والنصي (مرتبط بالفكرة رقم 1).
- ملاحظة تقنية: edge function جديدة (ask) — بحث دلالي/نصي بالملاحظات + gpt-4o-mini للإجابة.
- **معايير القبول** — أسئلة الاختبار (لازم يجاوب عليها كلها صح):
  - وين حطيت جواز السفر؟
  - آخر مرة اشتريت فلتر المكيف متى؟
  - شو مقاس الفلتر تبعي؟
  - وين فاتورة الأرضيات؟
  - شو الأشياء الموجودة في الكراج؟
  - متى صلحت السيارة؟
  - شو المنتجات الي جربتها وما عجبتني؟
  - شو الأشياء الي لازم أتذكرها قبل السفر؟

### 3. نقل ملاحظة بين المساحات — بزر أو بالسحب
- زر "انقل إلى…" على كل بطاقة ملاحظة بيفتح اختيار المساحة، **أو** ضغط مطوّل على البطاقة وسحبها (hold & drop) لتبويب المساحة الهدف.
- بينقل الملاحظة مع كل العناصر المستخرجة منها (مهام/مواعيد/مشتريات/أماكن).
- ملاحظة تقنية: تحديث `space_id` بجدولي notes و items (سياسات RLS بتسمح).

### 4. اقتراح تلقائي للمساحة حسب المحتوى
- التطبيق يقرأ محتوى الملاحظة (صوتية أو نصية) ويقترح المساحة المناسبة قبل الحفظ.
- مثال: "ذكّر الأولاد بموعد الأسنان" ← يقترح Family.
- المستخدم بيأكد الاقتراح أو بيغيّره بكبسة.

### 5. 📍 صورة للمكان — "وين أغراضي؟" بدليل بصري
- عند تسجيل مكان غرض: إمكانية إرفاق صورة (صوّر الدرج/الرف).
- لما تسأل "وين المفك؟" الجواب بيعرض الصورة مع المكان — موثوقية 100%.
- ملاحظة تقنية: رفع الصورة لـ Supabase Storage وربطها بعنصر الـ place.

### 6. "مين أخذها؟" — تتبع الاستعارة
- "أحمد أخذ المفك" ← عنصر place بحالة "مُعار" + اسم الشخص.
- لما تسأل وين المفك: "المفك مع أحمد من الثلاثاء".
- بتضرب الركيزتين معاً: أين أشيائي + العائلة.
- ملاحظة تقنية: حقل جديد بجدول items (holder + borrowed_at) أو نوع عنصر جديد.

### 7. إجابات بمصدر موثق
- كل جواب "وين" بيورجي الملاحظة الأصلية: مقطع الصوت + تاريخ التسجيل.
- ثقة ضد هلوسة الذكاء الاصطناعي، وتكلفة تنفيذ منخفضة (البيانات موجودة أصلاً).

### 8. قائمة تسوق عائلية مشتركة لحظية
- أي فرد بيضيف غرض ("سجّل: حليب") والتحديث فوري عند كل أفراد مساحة Family.
- تعليم "تم الشراء" لحظي للكل.
- استخدام يومي = عادة = التصاق بالتطبيق.
- ملاحظة تقنية: Supabase Realtime على جدول items.

### 9. إسناد مهام لأفراد العائلة
- "سارة: اشتري خبز" ← مهمة مسندة لسارة + إشعار push لها.
- متابعة حالة المهام المسندة داخل المساحة العائلية.
- ملاحظة تقنية: حقل assignee بجدول items + إشعارات.

### 10. تقويم عائلي موحّد
- المواعيد المستخرجة من ملاحظات أفراد العائلة بتتجمع بتقويم واحد مشترك.
- امتداد طبيعي لميزة الاستخراج الموجودة أصلاً.

### 11. أنواع استخراج جديدة (لخدمة Q&A)
- **مواصفات** (specs): "مقاس الفلتر 20x25x1" ← تجاوب "شو مقاس الفلتر تبعي؟"
- **آراء وتقييمات**: "جربت هالماركة وما عجبتني" ← تجاوب "شو جربت وما عجبني؟"
- **قوائم تحقق** (checklists): "قبل السفر: جواز، شاحن، دوا" ← تجاوب "شو لازم أتذكر قبل السفر؟"
- ملاحظة تقنية: توسيع extract function + kinds جديدة بجدول items.

## 🗺️ باقي مراحل الخطة الأصلية (M)

### M2 — متبقي: البحث
- بحث نصي داخل الملاحظات المفرّغة والعناصر المستخرجة (مهام/أماكن/مشتريات).

### M3 — الأسئلة + التذكيرات
- الأسئلة على البيانات: مغطاة جزئياً بالفكرة رقم 2 (Q&A).
- التذكيرات: push notifications للمواعيد والمهام المستحقة.

### M4 — حسابات + اشتراكات + لوحة الإدارة
- حسابات حقيقية (بريد/هاتف) بدل الدخول المجهول الحالي.
- اشتراكات Stripe: مجاني محدود / فردي / عائلي (الباقة العائلية هي الأساس حسب دراسة السوق).
- لوحة إدارة ويب: تتبّع المستخدمين والاشتراكات والإيراد.

### M5 — تلميع + نسخة تجريبية
- تلميع التصميم والأداء.
- نسخ EAS للآيفون والأندرويد، ثم تقديم App Store (بحاجة حساب Apple Developer $99/سنة).

## 💡 أفكار قيد التقييم (عصف ذهني 2026-09-22)

أفكار تنافسية مبنية على فجوات دراسة السوق (ذاكرة منزلية ثنائية اللغة + مشاركة عائلية + ثقة).
تُقيَّم واحدة واحدة قبل نقل أيٍّ منها لـ"متفق عليها".

**🎯 دقة الذاكرة المتخصصة**
- استخراج **الوعود** (promises) ومتابعتها، مش بس المهام.
- **بحث دلالي** عربي/إنجليزي: "الشي اللي حكيت عنه بالمطبخ" بيلاقيه بدون ذكر الاسم.

**🔍 البحث الذكي عن الأغراض المفقودة** (عصف 2026-09-22)
- 🛡️ **الوقاية قبل البحث**: لما تسجّل "أخذت المفك على الكراج"، التطبيق بيسألك بعد مدة "رجّعته لمكانه؟" — منع الضياع بدل البحث عنه.
- 🔍 **المحقق**: "ضيّعت الريموت" ← خطة بحث مرتبة حسب "الأماكن المشبوهة" لكل نوع غرض، مع شطب ما تم تفتيشه واقتراح الخطوة التالية.
- 👨‍👩‍👧 **العيلة كحسّاسات**: بثّ سؤال "مين شاف الريموت؟" لكل أفراد المساحة العائلية مع إشعار، والردود بتتجمع بمكان واحد.
- 📷 **الكاميرا كعين**: صوّر الغرفة والذكاء الاصطناعي (vision) بيدوّر على الغرض بالصورة وبيأشر عليه — بدون أي هاردوير.
- 📊 **تعلّم العادات**: إجابات احتمالية مرتبة من التسجيلات المتكررة ("الريموت 9 من 10 مرات كان بالصالون").

**👨‍👩‍👧 العائلة**
- **مصاريف البيت المشتركة**: "صرفت 40 على الخضرة" ← سجل وتقسيم تلقائي.
- **دعوة برابط** — كل عائلة بتجيب عائلة (نمو ذاتي / viral loop).

**🌍 عربي أولاً**
- تفريغ مضبوط **للهجات** (شامي/مصري/خليجي).
- واجهة عربية كاملة **RTL** من أول يوم.

**⚡ سرعة الوصول**
- **ويدجت iOS** + زر بمركز التحكم للتسجيل بضغطة.
- **Siri Shortcuts** (App Intents): "يا سيري، سجّل بموجود" / "اسأل موجود وين المفك" — بيحتاج كود iOS أصلي، بيجي مع نسخة EAS (M5).
- **Alexa Skill** مخصصة: "Alexa, ask Mawjood where's the screwdriver?" — المهارة بتتكلم مع الباكند تبعنا مباشرة؛ حساب مطوّر أليكسا مجاني.
- **Share sheet**: إرسال أي رسالة/صورة/رابط من أي تطبيق لموجود.
- **Apple Watch** للتسجيل السريع.

**🔮 ذكاء استباقي**
- الموعد المستخرج **بينضاف للتقويم تلقائياً** + تذكير قبله.
- **تذكير حسب الموقع**: "ذكّرني بالحليب لما أكون قرب السوبرماركت".
- **ملخص صباحي**: "شو عندي اليوم؟" — مهام + مواعيد + مشتريات.
- **مهام متكررة**: "كل أحد ذكّرني أكلم أمي".

**🔒 الثقة**
- قفل **Face ID** إضافي لمساحة Private.

**🗄️ الأرشيف**
- **استيراد تسجيلات قديمة**: رسائل واتساب الصوتية، فيديوهات عائلية، بريد صوتي ← تفريغ وتنظيم كجزء من الأرشيف. (بصدق: فقط ما تم تسجيله فعلاً — "صوت اللي بتحبهم قبل ما يصيروا ذكرى").
