# موجود — Mawjood: ملف المشروع الشامل
آخر تحديث: 2026-09-27

## الفكرة
تطبيق ذاكرة عائلي صوتي: بتسجل ملاحظة صوتية، بتتفريغ لنص، والذكاء الاصطناعي بيستخرج منها مهام ومواعيد ومشتريات وأماكن أشياء ومصاريف واستعارات — وبيجاوبك عنها لما تسأل.
الشعار: **"Lost it? Mawjood."** — موجود يعني "لقيتها".
الفلسفة: *شركة ذاكرة، مش شركة تخزين* — المقياس الوحيد: هل بيجاوب أحسن؟
الركيزتان: (1) **أين أشيائي؟** — ذاكرة الأغراض والأماكن، (2) **تنسيق العائلة**.
السوق: أمريكا أولاً، عربي/إنجليزي من اليوم الأول.

## المساحات والخصوصية
- 🔒 **الخاصة (private)**: إلك لحالك — ممنوع أي حدا يشوفها، حتى العائلة.
- 👨‍👩‍👧 **العائلة (family)**: مشتركة مع أفراد العائلة، إلها مدير (عادةً إنت). أول عائلة مجانية، عائلات زيادة = اشتراك.
- 💼 **الشغل (work)**: إلك لحالك — شغل واجتماعات وعميل.
- التبويبات: كل مساحة فيها تبويبات (📄 الأوراق للفواتير والجوازات، 🛒 التسوق، 📦 أشيائي...) + تبويبات مخصصة (＋).
- 💬 **الشات خاص بالمستخدم فقط** — العائلة ما بتشوف محادثاتك.
- كلمات السر والأكواد وأرقام الهوية: **لا تُحفظ أبداً** — تُستعمل للمهمة الحالية وبس.

## المزايا المبنية (وشو بتعمل كل وحدة)
- 🎙️ **الصوت → نص**: تسجيل صوتي → تفريغ (Groq Whisper مجاني) → **الصوت يُمسح فوراً** (قرارك: بنكتفي بالصور).
- 🧠 **الشات الحي**: وكيل ذكاء (GPT-5-mini) بعشر أدوات — بيحفظ، بينقل، بيدور، بيجاوب، وبيتصرف على بياناتك.
- 🧭 **محرك التوجيه**: 4 طبقات (صريح ← متعلَّم من تصحيحاتك ← قواعد ← الذكاء) بتقرر وين تروح كل ملاحظة. كل نقل بتعمله بصير قاعدة دائمة.
- 🧠 **محرك الذاكرة**: تعلّم ضمني بعد كل محادثة + حقائق صريحة ("تذكر أن...") + دمج ليلي للحقائق المتشابهة.
- 📦 **أشيائي**: "اشتريت مفك" ← غرض + مكانه + سعره. "وين المفك؟" ← "موجود في...".
- 🤝 **الاستعارة**: "أحمد أخذ المفك" ← تسجيل؛ "مين أخذها؟" ← "موجود مع أحمد"؛ "رجع" ← إغلاق.
- 🛒 **قوائم التسوق**: "يا أحمد جيب حليب" ← قائمة باسم أحمد + تنبيه له؛ المشتريات بتروح للأرشيف.
- ✅ **المهام**: "أحمد: صلّح الباب" ← مهمة مُسندة؛ ✅/🗑️ بالسحب.
- 📅 **الأجندة**: مواعيد بتاريخ ووقت + WeekStrip + مشاركة واتساب.
- ☀️ **الملخص الصباحي**: "شو عندي اليوم؟" ← مواعيد + مهام مستحقة + تسوق + استعارات بفقاعة وحدة.
- 💰 **مصاريف البيت**: "صرفت 40 على الخضرة" ← تسجيل؛ "قديش صرفنا هالشهر؟" ← ملخص.
- 🔍 **المحقق**: "ضيّعت الريموت" ← خطة بحث مرتبة + "لقيته!" ← بيحفظ المكان الجديد.
- 📣 **بث العيلة**: "اسأل العيلة مين شاف الريموت؟" ← تنبيه لكل الأفراد.
- 📷 **صور الملاحظات**: صورة مع الملاحظة (بتضل، مش زي الصوت).
- 🔊 **الرد الصوتي**: ملاحظة صوتية ← جواب منطوق.
- 💬 **سجل المحادثات + ردود فعل** على الفقاعات (❤️ 👍 ... 👎).
- 🗑️ **سلة مهملات + تراجع 5 ثواني** بعد الحذف.
- 🌙 ليلي / 🌐 عربي-إنجليزي / 🎓 إعداد تفاعلي / 👥 دعوات العائلة بالكود + طرد بتنبيه.
- 💳 **الاشتراكات والحدود** (لوحة الإدارة): عدد العائلات، الخزائن السرية، مدة حفظ الشات، مدة السلة، التبويبات المخصصة — مع سجل منح.

## العام vs الخاص vs الوهمي 👻
- **عام**: مساحة العائلة (للأعضاء فقط)، موقع التجربة (أي حدا معه الرابط)، كود المشروع على GitHub (عام حالياً — بتقدر تخليه خاص).
- **خاص**: مساحتك الخاصة، محادثاتك، صورك — إلك لحالك ومحمية بصلاحيات قاعدة البيانات.
- **وهمي (الشبح)**: كلمة سر وهمية بتفتح **خزائن وهمية** فيها ملاحظات عادية مُختلقة، وشاشة إدارة وهمية **طبق الأصل** من الحقيقية — بحيث لو حدا أجبرك تفتح، ما بيلاقي شي غريب. القاعدة الذهبية: **أي أثر مرئي لوجود الميزة السرية هو خلل بحد ذاته**.
