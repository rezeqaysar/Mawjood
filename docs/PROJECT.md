# موجود — Mawjood: ملف المشروع الشامل
آخر تحديث: 2026-10-09

## الفكرة بجملة
تطبيق ذاكرة عائلي **صوت-أولاً**: بتسجل ملاحظة صوتية، بتتفريغ لنص، والذكاء الاصطناعي بيستخرج منها مهام ومواعيد ومشتريات وأماكن أغراض ومصاريف واستعارات — وبيجاوبك عنها لما تسأل.

الشعار: **"Lost it? Mawjood."** — موجود يعني "لقيتها".

الفلسفة: *شركة ذاكرة، مش شركة تخزين* — المقياس الوحيد: **هل بيجاوب أحسن؟**

الركيزتان: (1) **أين أشيائي؟** — ذاكرة الأغراض والأماكن، (2) **تنسيق العائلة** — قوائم تسوق ومهام ومواعيد مشتركة.

السوق: **أمريكا أولاً** (أمريكيين + عرب أمريكا)، عربي/إنجليزي من اليوم الأول.

الاسم: **Mawjood (موجود)** مؤقتاً — قابل للتغيير قبل الإطلاق بتكلفة صفرية. الزاوية التسويقية: تعليم السوق الأمريكي كلمة عربية واحدة. البدائل المحفوظة: Dallni، Laqit. (Balak مرفوضة — في منتج Chrome بنفس الاسم balak.app؛ الدومين mawjood.com مأخوذة من 2012 — البديل getmawjood.com).

## شو الفجوة اللي بيملّيها
بحث السوق (22 سبتمبر 2026): في طلب حقيقي. الفجوة = تطبيقات الملاحظات بتخزّن بس ما بتجاوب؛ المطلوب: تصنيفات حياتية + "وين أغراضي؟" + تتبع مشتريات + دعم عربي حقيقي.

## المساحات والخصوصية
- 🔒 **الخاصة (private)**: إلك لحالك — ممنوع أي حدا يشوفها، حتى العائلة.
- 👨‍👩‍👧 **العائلة (family)**: مشتركة، إلها مدير (عادةً إنت). أول عائلة مجانية؛ عائلات زيادة = احذف وحدة قديمة أو ادفع (slot paywall). عيلتك الأصلية **ما بتنحذف أبداً** (إنت الأدمن). تبديل بين العائلات من نافذة واحدة + مغادرة بخطوتين.
- 💼 **الشغل (work)**: إلك لحالك — شغل واجتماعات وعميل.
- **التبويبات**: كل مساحة فيها تبويبات (📄 أوراقي للفواتير والجوازات، 🛒 التسوق، 📦 أشيائي، ✅ المهام، 📅 الأجندة، 💰 المصاريف...) + تبويبات مخصصة بالـ＋ (اسم + إيموجي). تبويبات العائلة ظاهرة للكل؛ الخاصة/الشغل للمالك فقط. الباقة المجانية = 3 تبويبات مخصصة لكل مساحة (خطاف مدفوع).
- 💬 **الشات خاص بالمستخدم فقط** — العائلة ما بتشوف محادثاتك.
- 🔑 كلمات السر والأكواد وأرقام الهوية: **لا تُحفظ أبداً** — تُستعمل للمهمة الحالية وبس، ومحرك الذاكرة ممنوع يقرب عليها.

## المزايا المبنية (وشو بتعمل كل وحدة)

### الإدخال والاستخراج
- 🎙️ **الصوت → نص**: تسجيل صوتي → تفريغ (Groq Whisper مجاني) → **الصوت يُمسح فوراً** (قرارك: بنكتفي بالصور).
- 🧭 **محرك التوجيه**: 4 طبقات (صريح ← متعلَّم من تصحيحاتك ← قواعد ← الذكاء) بتقرر وين تروح كل ملاحظة. كل نقل بتعمله بإيدك بصير قاعدة دائمة. المسار السريع الحتمي للجمل الواثقة (~1 ثانية بدل ~6).
- 📷 **صور الملاحظات**: صورة مع الملاحظة — بتضل محفوظة (مش زي الصوت)، والذكاء بيشوفها وبيجاوب عنها.

### الذكاء
- 🧠 **الشات الحي**: وكيل ذكاء (ReAct ≤5 خطوات) بعشر أدوات — بيحفظ، بينقل، بيدور، بيجاوب، وبيتصرف على بياناتك. **تبويب-واعي**: بيشوف تبويباتك وبيقترح تبويبات جديدة (من غير ما ينشئ من نفسه) مع بطاقة اقتراح تقبل/ترفض.
- 🧠 **محرك الذاكرة v2**: تعلّم ضمني بعد كل محادثة + حقائق صريحة ("تذكر أن...") + دمج ليلي للحقائق المتشابهة (اضمحلال 90 يوم، سقف 200). أدوات: تذكّر / انسى / اعرض ذكرياتي.
- 🛡️ **حارس النطاق**: كشف حتمي قبل الوكيل — معرفة عامة/طقس/أخبار/نكت ← "هاد خارج نطاقي".
- 👍👎 **تغذية راجعة** تحت كل جواب (إشارة تعلّم مستقبلية).

### الأشياء والبيت
- 📦 **أشيائي**: "اشتريت مفك" ← غرض + مكانه + سعره. "وين المفك؟" ← "موجود في...".
- 🤝 **الاستعارة**: "أحمد أخذ المفك" ← تسجيل + تاريخ استحقاق؛ "مين أخذها؟" ← "موجود مع أحمد"؛ زر "✅ رجع" بخطوتين.
- 🔍 **المحقق**: "ضيّعت الريموت" ← خطة بحث مرتبة + شطب تفاعلي + "لقيته!" ← بيحفظ المكان الجديد كذاكرة مكان.
- 🕰️ **الخط الزمني للغرض** + 📊 **تعلّم العادات** ("الريموت عادةً بالصالون — 9 من 10 مرات") + 👀 **الوقاية** (مراقبة بتذكّرك ترجّع الغرض بعد 4 ساعات).
- 🛒 **قوائم التسوق**: "يا أحمد جيب حليب" ← قائمة باسم أحمد + تنبيه push له؛ المشتراة بتروح للأرشيف؛ "غير موجود" بيسجّل الناقص. المشاركة عبر ورقة المشاركة الأصلية (iOS) مع بديل واتساب.
- 🧠 **التسوق الذكي**: "شو ناقصنا؟" ← إيقاعات الشراء من سجلّك ("حليب كل 5 أيام").
- ✅ **المهام**: "أحمد: صلّح الباب" ← مهمة مُسندة لشخص؛ ✅/🗑️ بالسحب.
- 📅 **الأجندة**: مواعيد بتاريخ ووقت + شريط الأسبوع + مشاركة واتساب.
- ☀️ **الملخص الصباحي**: "شو عندي اليوم؟" ← مواعيد + مهام مستحقة + تسوق + استعارات بفقاعة وحدة.
- 💰 **مصاريف البيت**: "صرفت 40 على الخضرة" ← تسجيل فوري؛ "قديش صرفنا هالشهر؟" ← ملخص بالمجموع والتقسيم حسب الشخص.

### العائلة
- 👥 **دعوات بالكود** (7 أيام، 10 استخدامات) + طرد بتنبيه + تبديل العائلات.
- 📣 **بث العائلة**: "اسأل العيلة مين شاف الريموت؟" ← تنبيه push لكل الأفراد ما عدا السائل.

### الصوت والواجهة
- 🔊 **الرد الصوتي**: ملاحظة صوتية ← جواب منطوق (TTS على الجهاز، مجاني)؛ نص ← نص. زر تبديل 🔊/🔇 بالدرج.
- 💬 **سجل المحادثات** (زي شات جي بي تي) + حذف بعدّاد + ردود فعل على الفقاعات (❤️ 👍 👎).
- 🗑️ **سلة مهملات + تراجع 5 ثواني** بعد الحذف.
- 🌙 ليلي (تلقائي 19:00–07:00) / 🌐 عربي-إنجليزي (الإنجليزية الافتراضية باختيارك) / 🎓 إعداد تفاعلي.

### الحسابات
- حسابات حقيقية برابط سحري بالإيميل؛ الوضع المجهول بيترقى لحساب دائم (نفس المعرّف، البيانات محفوظة).
- 📥 **تصدير الحساب** و🗑️ **حذف الحساب** من الدرج (الحذف: الملكية بتنتقل لأقدم عضو، العضويات بتنمسح، التخزين بيتمسح، حساب الدخول بيتحذف — وبصمات الخزائن **ما بتتصدّر أبداً**).

## 👻 الخزائن السرية (الميزة الفارقة)
- 🔐 **خزائن سرية متعددة** بتبويبات سرية — بصمات bcrypt (النص الأصلي اتشال نهائياً)، قدرة إدارة HMAC بعشر دقائق.
- 👻 **مفتاح الشبح**: كلمة سر وهمية بتفتح **خزائن وهمية** فيها ملاحظات عادية مُختلقة + شاشة إدارة وهمية **طبق الأصل** من الحقيقية — لو حدا أجبرك تفتح، ما بيلاقي شي غريب. القاعدة الذهبية: **أي أثر مرئي لوجود الميزة السرية هو خلل بحد ذاته** (صوت مسموع بيمسح الملاحظة الصوتية فوراً، سلة وهمية مخفية، قفل بالخلفية، معالج تعبئة وهمية، تحذير الإكراه بخطوتين).
- 🎯 **التميّز المخطط**: **"اسأل خزنتك"** — مساعد ذكاء **داخل** الخزنة السرية (المنافسين Keepsafe / Private Photo Vault / CoverMe عندهم صفر ذكاء؛ وتطبيقات الذكاء الخاصة ما عندها خزنة). الخطوة الجاية: خزنة ملفات/مستندات سحابية + إجابات واعية بالخزنة.
- قرار استراتيجي (2 أكتوبر 2026): منكمل ببناء **Mawjood كمنصة**، ونظام الخزنة بيتطور **فوقها** مش كتطبيق منفصل.

## 💳 الاشتراكات ولوحة الإدارة
- **لوحة إدارة ويب** (admin.html، عربي RTL): دخول بـ x-admin-token + service_role؛ التوكن بيظهر مرة وحدة وما بيتخزن.
- **الباقات**: أسعار ومدد بتتعدل من اللوحة مباشرة؛ **عروض ترويجية**؛ **كتالوج مزايا بمفاتيح إيقاف حقيقية** (الخزائن / العائلة الإضافية / التبويبات المخصصة مربوطة فعلياً؛ الرد الصوتي / السلة الموسعة / سجل الشات الموسع مزروعة بس لسا مش مربوطة).
- **منح لكل مستخدم**: حدود مخصصة (عائلات، خزائن، مدة الشات/السلة، تبويبات) بالإيميل أو المعرّف، مع انتهاء اختياري وسجلّ منح.
- **إدارة المستخدمين**: ملف، حظر دائم، إيقاف بساعات؛ **بثّات** (بطاقات داخل التطبيق قابلة للإغلاق)؛ **إعدادات عامة** آمنة للمجهولين تُقرأ عند الدخول.
- الباقة المجانية عند الإطلاق (معلّقة — بتتثبت قبل الإطلاق): عائلة 1، خزنة 1، سلة 0 أيام، شات 7 أيام، 3 تبويبات.
- **Stripe مؤجّل** بقرارك ("خلينا نأجل موضوع الدفع شوي") — بيتنفذ لما التطبيق يجهز.
